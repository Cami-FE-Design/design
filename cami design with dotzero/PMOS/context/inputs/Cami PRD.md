# Cami PRD (SSOT)

> **This is the canonical PRD for Cami, migrated from the git **`Cami-PRD/`** folder on 2026-07-13. Notion is now the SSOT.** The local md files are an archive snapshot as of that date. If a product question is unanswered elsewhere, the answer lives here or is explicitly flagged as an open question.

## How to use this SSOT

1. Start with **01 Thesis**. Every other page ladders up to it.
2. **03 Payment Engine** is load-bearing. Most feature briefs reference assumptions set there. Read it before writing any new feature brief.
3. Feature briefs live under **05 Feature Briefs**, one page per feature.
4. Raw source material (founder brief, SOW analysis, Petverse extracts, Moego reference) lives under **Sources**.
5. Decisions that resolve open positions are logged in **06 Operating Layer** under Decision log.
