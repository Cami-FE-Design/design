# Workspace structure

**Start here:** [`artifact-flow.md`](./artifact-flow.md) — which file holds the answer at each step, objective through metric.

- `artifact-flow.md` — the twelve-node chain and where every doc type belongs
- `nodes/` — [index of every node](./nodes/README.md), including the ones in other repos, plus who owns what
- `work/specs/brd/` — business requirements, initiative-scale
- `work/specs/prd/` — PRDs, canonical
- `work/specs/use-cases/` — one spec per use case ID, all paths and alternates
- `work/*/outputs/` — where mySecond skills write. Promote the keepers into the folders above
- `work/discovery/` — interviews, JTBD, journey maps
- `work/_templates/` — [table-first](./work/_templates/table-first.md) (any doc), [brd](./work/_templates/brd.md) (initiative requirements)
- `context/` — company / product / personas / competitors (auto-loaded into Claude via `@import` in CLAUDE.md)
- `.claude/skills/` — installed skills (synced from mysecond.ai)
- `.claude/agents/` — installed agents
- `workflows/` — installed workflows
- `.claude/sync-state.json` — local sync ledger (don't edit by hand)
- `.claude/napkin.md` — your scratchpad (corrections, preferences, ongoing notes)

Generated by `mysecond init`. Safe to edit any of the above; mySecond never overwrites customer-authored content.
